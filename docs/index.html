What it is

An unofficial, play-money recreation of Bally's classic Blazing 7s three-reel slot machine in plain HTML5 Canvas, Web Audio and vanilla JavaScript. The reels use the weights of the real PAR sheet (72 virtual stops mapped onto 22 physical stops per reel), so the machine hits 12.05% of pulls and returns 91.96% / 92.52% / 92.70% for one, two and three coins, exactly as published.

Features

Stepper physics

Snap wind-up, blurred spin, abrupt deceleration and a stiff spring settle; reels stop left to right with a clunk and rising chimes.

Virtual reels

Near-misses happen the way they do on the real machine: blanks beside the Blazing 7 carry extra weight.

Buy-a-pay and Double Jackpot

7s need two coins, the third coin doubles them, and the Double Jackpot symbol on reel 3 turns two Blazing 7s into 5,000 coins.

The cabinet

Chrome rails, candle, chase lamps, LED meters, VFD message line, belly-glass pay table with the lit coin column, and a handle you can pull.

Synthesized sound

Coin clinks, lever ratchet, motor whir, stop chimes, counting dings, jackpot siren, hopper rattle — all generated live.

Verified maths

node tools/rtp-sim.js prints the par-sheet report; node tools/smoke.mjs plays the machine headless.

Run it yourself

Clone or download the project and open index.html, or serve the folder (python -m http.server 8766, or start.cmd on Windows). The README has the configuration reference and the tools.
